## Technical Root Causes

### Streamlit 1.47.1 Date Input Bug
The primary issue appears to be a bug in Streamlit version 1.47.1 where `st.date_input` widgets cannot handle partial manual text editing states. This is confirmed by:
- Even minimal test apps crash with date editing
- Text input alternatives work without issues
- Original version worked before multi-page integration

### Multi-page State Management
Streamlit's multi-page architecture creates widget state conflicts where:
- Page navigation resets widget states
- Session state doesn't properly isolate between pages
- `st.rerun()` calls cause navigation issues
